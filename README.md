A full-stack **School Examination Management System (SEMS)** developed using **Node.js, Express.js, PostgreSQL (NeonDB), HTML, CSS, and Vanilla JavaScript**.

This educational management system automates examination workflows including student management, teacher management, class management, exam scheduling, seat allocation, attendance tracking, marks management, result processing, report card generation, and academic record management through a responsive web application.
